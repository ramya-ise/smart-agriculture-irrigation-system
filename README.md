# Smart Agriculture and Irrigation System

## About the Project
An Arduino-based smart agriculture and irrigation system that monitors soil moisture, temperature, humidity, and water level to automate water pumping.

## Technologies Used
- Arduino Uno R3
- C/C++ (Arduino)
- DHT11 Sensor
- Soil Moisture Sensor
- Water Level Sensor
- 5V Relay Module
- DC Water Pump

## Features
- Monitors soil moisture
- Measures temperature and humidity
- Monitors water level
- Automatically controls water pumping
- Prevents pumping when the water level is too low

## Hardware
- Arduino Uno R3
- DHT11
- Soil Moisture Sensor
- Water Level Sensor
- Relay Module
- DC Water Pump

## Project Purpose
The system helps automate irrigation and reduce unnecessary water usage by activating the pump when the soil becomes dry.
